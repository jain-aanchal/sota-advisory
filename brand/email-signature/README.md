# SOTA Advisory email signature

Brand-consistent HTML email signature: logo left, charcoal name, gold title and
links, warm hairline rule. Palette matches the proposal template.

## Files

| File | Use |
|---|---|
| `signature-preview.html` | Open in a browser, select the block between the two thin lines, copy, paste into your email client. Logo is embedded as base64, so nothing needs hosting. |
| `signature-embedded.html` | Raw HTML with the embedded logo, for clients that accept pasted source (Apple Mail, Outlook desktop, Front, HubSpot). |
| `signature-hosted.html` | Same signature pointing at `https://sotaadvisory.com/sota-logo-signature.png`. Preferred once the site is deployed: keeps sent mail light and stops Outlook showing the logo as an attachment. |
| `../../public/sota-logo-signature.png` | The logo sized for signatures (320x175, displays at 160x87). Served from the site root. |

## Install

- **Gmail:** Settings → See all settings → General → Signature → Create new → paste → Save Changes.
- **Apple Mail:** Settings → Signatures → paste. Uncheck "Always match my default message font."
- **Outlook web:** Settings → Mail → Compose and reply → paste.
